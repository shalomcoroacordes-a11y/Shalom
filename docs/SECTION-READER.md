# Lectura por secciones (10 y 74)
Primera etapa: motor de navegación sobre filas ya interpretadas, incluyendo indicaciones y acordes, y ajuste medido dentro de Chromium offline. El modo tradicional sigue siendo el predeterminado.
El ajuste automático maximiza el tamaño de fuente dentro del ancho y alto disponible, respetando el mínimo legible. Si no cabe al mínimo, se conserva el desplazamiento. El pellizco desactiva el ajuste automático de esa vista y conserva la posición de los acordes.
El canto individual Android incorpora selector de secciones, anterior/siguiente y tres modos de tamaño; A+/A− y pellizco siguen funcionando. El presupuesto de alto inicial usa las dimensiones de ventana menos un margen para los controles; no equivale aún a la medición exacta del área visible. Pendiente: navegación común de colecciones, altura de viewport real, pantalla completa y pruebas físicas, adaptación web/PWA. No hay cambios de base de datos, versiones de APK o dependencias.
